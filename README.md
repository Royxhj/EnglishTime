# EnglishTime · 패밀리 영어 공부

가족이 함께 쓰는 영어 학습 웹앱이에요. 초등 1학년부터 성인까지 **6단계**로 단어 · 문법 · 대화 · 읽기 · 듣기 · 말하기 · 쓰기를 공부하고 문제를 풀 수 있어요.

**👉 바로 쓰기: https://royxhj.github.io/EnglishTime/**

휴대폰 브라우저에서 열고 "홈 화면에 추가"를 누르면 앱처럼 설치돼요. 한 번 열면 인터넷이 없어도 쓸 수 있어요.

---

## 단계

| 단계 | 대상 |
|---|---|
| 🌱 초등 1~2학년 | 알파벳 · 파닉스, 기초 단어 |
| 🌿 초등 3~4학년 | 교과서 기본 표현 |
| 🚀 초등 5~6학년 | 문장 만들기, 불규칙 동사 시작 |
| 📘 중학교 | 중1~중3 교과서 문법 · 의사소통 |
| 🎓 고등학교 | 고1~고3 문법 · 수능 어휘 · 숙어 |
| 💼 성인 | 헷갈리는 기본기, 업무 · 여행 실전 영어 |

## 기능

### ☀️ 매일
- **오늘의 학습**: 내 단계에 맞춘 단어 5 + 문법 3문제 (5분)
- **📝 오답노트**: 틀린 단어 · 문법 · 연습 문제를 모아서 연속 2번 맞히면 졸업
- **🎯 이번 주 목표**: 문제 수 · 공부한 날 · 과제를 정하고 진행률 보기
- **📊 학습 리포트 · 🏅 배지 · 가족 주간 순위**

### 📚 배우기
- **🔤 파닉스**: 13주제, 소리를 듣고 글자 고르기
- **📇 단어장**: 단계별 약 1,360단어, 발음 · 예문, 간격 반복 플래시카드
- **📘 문법 노트**: 단계별 문법 99주제(설명 음성 · 그림 예문 · 연습 6문제), 독해 문법 12주제
- **💬 대화 표현**: 초등 · 중학교 · 고등학교 · 성인 상황별 38주제
- **📖 읽기 연습**: 지문 42개, 이어 듣기 · 따라 읽기 · 단어 뜻 보기
- **🔁 불규칙 동사**: 3단계 96개, 변화 모양별 정리, 가리고 외우기, 테스트
- **🔀 to부정사 · 동명사**: 원리 설명과 동사 44개, 묶음별 테스트
- **🧩 숙어 · 구동사**: 60개, 예문과 테스트
- **🔠 접두사 · 접미사**: 20개 조각으로 처음 보는 단어 뜻 짐작하기

### 🗣️ 말하기 · 듣기 · 쓰기
- **🎙️ 따라 말하기**: 예문을 듣고 말하면 음성 인식으로 채점 (안드로이드 · PC 크롬, 엣지)
- **🎧 듣기 평가**: 남녀 목소리 대화를 듣고 문제 풀기, 대본과 해설
- **✍️ 영작 연습**: 한국어 뜻을 보고 단어 배열 또는 직접 쓰기
- **🖊️ 받아쓰기**

### ✏️ 문제 풀기
- 단어 퀴즈 · 철자 쓰기 · 문법 문제 · 끊어 읽기 · 독해 문제
- **🧩 가로세로 낱말**: 할 때마다 단어장에서 새 퍼즐을 만들어요
- **📝 단원 모의고사**: 학년별 20문제, 100점 만점과 영역별 점수

## 개인 정보

- 가족 이름과 학습 기록은 **각 기기의 브라우저 안에만** 저장되고, 어디로도 보내지 않아요.
- 다른 기기로 옮기려면 ⚙️ 설정 → 기록 백업에서 파일로 저장한 뒤 새 기기에서 불러와요.
- 검색 엔진에는 노출되지 않도록 설정되어 있어요.

## 기술

- 빌드 도구나 서버 없이 HTML · CSS · JavaScript만으로 만든 정적 웹앱(PWA)이에요.
- 발음은 브라우저 음성 합성(Web Speech API)을 써서 기기에 따라 목소리가 달라요.
- 이 저장소에는 배포용 파일만 있어요.
